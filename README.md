# 浮生 · 海上日记

面向手机横屏的 3D 木筏生存游戏原型，支持电脑浏览器。资源全部在本地，不依赖网络。

- 在线试玩：https://adrift-raft-survival.pages.dev
- 源码仓库：https://github.com/jasonyang-5003/adrift-raft-survival （私有仓库）
- 托管：Cloudflare Pages；生产分支为 `main`，推送后自动构建发布。

## 开始游玩

电脑可直接用 Chrome / Edge 打开 `index.html`。推荐通过本地服务游玩；在此文件夹执行：

```powershell
python -m http.server 8000 --bind 0.0.0.0
```

电脑打开 `http://localhost:8000`。手机连接同一 Wi-Fi，在浏览器打开 `http://电脑的局域网IP:8000`。Windows 首次可能需要允许此服务通过专用网络防火墙。请勿把本地开发服务器直接暴露到公网。

也可将整个文件夹部署到支持静态网页的网站，通过 HTTPS 链接在手机打开。必须保留 `vendor/three.min.js`。

## 发布到 Cloudflare Pages

发布前运行 `node scripts/build.mjs`，只把生成的 `dist/` 目录上传到 Cloudflare Pages。该目录包含运行游戏所需的网页、程序、样式及本地 3D 引擎，不包含测试截图、压缩包或本机工具。

在 Cloudflare Pages 连接 GitHub 仓库时，设置构建命令为 `npm run build`，输出目录为 `dist`。项目不需要安装任何运行依赖。

## 操作

- 手机：左侧摇杆移动，拖动海面旋转镜头，右侧按钮抛竿、收杆、攻击。
- 咬钩后点收杆，按住增加拉力，松开降低拉力；保持光标在绿色区，填满进度。
- 电脑：WASD / 方向键移动，空格钓鱼、收杆、攻击，E 打开背包，Esc 取消建造 / 关闭面板 / 设置。
- 背包、制作、建造、商人和祈愿在底部；右下小按钮吃食物、喝水、睡觉。
- 建造：在面板选择建筑，点击海面上的绿色网格，再点确认建造。

## 已有玩法

- 五种开局天赋中随机三选一；十二种祝福卡，三选一，叠加至三级。
- 可互动钓鱼，鱼类、材料、宝箱、两种武器图纸及两类海蟹。
- 生命、饱腹、饮水、每日体力、鱼竿耐久，睡眠跨天。
- 四级木筏成长，与等级联动的鱼竿耐久和等级。
- 烤架、烤鱼、储物箱、净化器、床、木矛、铁矛、海员弯刀。
- 木筏逐格扩建，围墙与棕叶小屋，最多 49 格。
- 贝币、卖鱼、净水每日高价收购限额、物物交换和补给购买。
- 五步漂流手记奖励，自动存档、JSON 导入导出、省电模式、轻音效。
- 无体力可应急钓鱼，鱼竿完全损坏可免费应急修复，死亡可保留装备继续。

## 原型说明

时间、怪物和设备生产在面板打开或页面进入后台时暂停。设备不进行离线生产。存档保存在当前浏览器，跨设备需要导出后导入。基础背包容量不设上限，储物箱目前主要是可建造场景道具。第一版没有岛屿登陆、航海移动、多人或在线账户。

场景和模型均由程序生成。Three.js r160 随项目保存在 vendor 下，采用 MIT 许可证，版权信息见 vendor/LICENSE.txt。
